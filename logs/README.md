# Logs Directory

This directory stores rolling log files generated by the service.

Files:
- `yakeen-<date>.log` — All YAKEEN API operations
- `error-<date>.log` — Error-level messages only
- `access.log` — HTTP access log (Morgan)
- `pm2-out.log` — PM2 stdout
- `pm2-error.log` — PM2 stderr

> Log files are excluded from version control via `.gitignore`.
